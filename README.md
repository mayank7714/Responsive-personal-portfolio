# 🌐 Personal Portfolio Website

A modern and responsive Personal Portfolio Website built using **HTML5** and **CSS3**. This project showcases personal information, technical skills, projects, and contact details through a clean and user-friendly interface.

---

## 📖 Project Overview

This portfolio website is designed to present a developer's profile in a professional manner. It includes sections for introducing yourself, highlighting your skills, displaying projects, and allowing visitors to contact you.

The website is fully responsive and works seamlessly across desktops, tablets, and mobile devices.

---

## ✨ Features

✅ Responsive Navigation Bar  
✅ Professional Hero Section  
✅ About Me Section  
✅ Skills Showcase Cards  
✅ Projects Display Section  
✅ Contact Form  
✅ Footer Section  
✅ Mobile-Friendly Design  
✅ Clean and Modern UI
